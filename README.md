# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

试映时还能直接在卡片上做现场反应标记：

- 每张片段卡片点「▶ 进入放映」即进入放映中，此时卡片上可即时累计 👏 掌声 / 🧊 冷场 / ❓ 提问。
- 同一时刻只有一段处于放映中；换段前先点「结束本轮」（总览栏或放映卡片上），其余片段的放映按钮在此期间禁用。
- 反应记录保存在片段本身（按片段 id 关联）：拖动调序、上下移后记录仍属于原片段；删除片段时其反应记录一并清除。
- 顶部「现场反应总览」显示正在放映的片段、已有记录的片段数和三类反应总数，三类反应分别用橙 / 蓝 / 紫区分。
- 所有数据（含放映中状态和反应计数）都存在 localStorage，纯前端无后端，重开页面可继续。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
